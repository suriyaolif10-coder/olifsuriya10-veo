# ห้องคุมงานรายงานประจำเดือน

เว็บ "ห้องคุมงาน" สำหรับพัฒนาการอำเภอ ใช้ติดตามรายงานประจำเดือนของเจ้าหน้าที่ในสำนักงานพัฒนาชุมชนอำเภอ

- ภาพห้องทำงานแบบ 3 มิติ (isometric) มีโต๊ะ ตัวละคร และป้ายชื่อพร้อมสถานะของเจ้าหน้าที่แต่ละคน
- สถานะรายงาน 4 ระดับ: ยังไม่ส่ง / กำลังทำ / ส่งแล้ว / ตรวจแล้ว และแจ้ง "เลยกำหนด" อัตโนมัติเมื่อเลยวันครบกำหนด
- รายงานแต่ละเรื่องมีวันครบกำหนดประจำเดือน (เช่น ทุกวันที่ 10) และเก็บสถานะแยกรายเดือน
- แก้ชื่อเจ้าหน้าที่ สีประจำตัว เพิ่ม/ลบรายงาน และใส่หมายเหตุได้
- บันทึกการอัปเดตล่าสุด และรายการใกล้ครบกำหนด / ค้างส่ง
- ใช้บนมือถือได้

## ข้อมูลเก็บที่ไหน

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์บนเครื่องที่ใช้งานเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์
ใช้ปุ่ม **สำรองข้อมูล** เพื่อดาวน์โหลดไฟล์ `.json` และ **นำเข้าข้อมูล** เพื่อย้ายไปเครื่องอื่น

## เปิดใช้งานด้วย GitHub Pages

1. ไปที่ **Settings → Pages** ของ repo นี้
2. Source เลือก **Deploy from a branch** แล้วเลือก branch ที่มีไฟล์ `index.html` และโฟลเดอร์ `/ (root)`
3. กด Save รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์ได้โดยตรง

## ไฟล์

- `index.html` โครงหน้า
- `style.css` หน้าตา
- `app.js` การทำงานทั้งหมด (ไม่ต้องติดตั้งอะไรเพิ่ม)
